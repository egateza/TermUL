## Baru

- **Ikuti folder terminal**: tombol baru (ikon link) di toolbar panel SFTP. Saat aktif, panel SFTP di samping terminal ikut pindah ke folder kerja shell setiap kali Anda menekan Enter (`cd /var/log` → panel membuka `/var/log`). Tidak ada yang diketik ke shell. Di vim, htop, atau less tidak dicek. Default mati; pengaturannya berlaku untuk semua tab.
- **Lepas tab ke window baru**: klik kanan tab → **Lepas tab ke window baru**, menu **Terminal → Lepas tab ke window baru**, atau seret tab menjauh dari baris tab. Sesi tetap berjalan, termasuk tab split. Kembalikan lewat **Terminal → Kembalikan ke window utama**. Shortcut, konfirmasi tutup/keluar, dan pengaturan tetap berlaku di window terpisah.
- **Breadcrumb path** di panel SFTP remote dan lokal: klik bagian path untuk langsung membuka folder itu. Klik area kosong atau tombol pensil untuk mengetik path (Enter buka, Esc batal). Klik kanan untuk menyalin path. File bisa di-drop ke salah satu bagian path untuk upload/download ke folder itu.

## Perbaikan

- Alt+F4 di window tab terpisah hanya menutup window itu, bukan seluruh aplikasi.
- Transparansi latar terminal tidak lagi diterapkan di window tab terpisah (window biasa tanpa transparansi), sehingga tidak meninggalkan sisa gambar.

## Catatan

- **Ikuti folder terminal** butuh server yang menerima variabel `LC_*` (bawaan Ubuntu/Debian, `AcceptEnv LANG LC_*` di `sshd_config`), atau shell yang mengirim OSC 7. Kalau tidak didukung, TermUL menampilkan pesan dan panel tidak ikut pindah.
