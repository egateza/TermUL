## Baru

- **Terminal lokal**: buka shell di komputer sendiri (Ctrl+Shift+O / ⇧⌘O) berdampingan dengan tab SSH, termasuk split. Shell terdeteksi otomatis (Windows: PowerShell, cmd, Git Bash, WSL; macOS: zsh, bash, fish). Profil sendiri (program, argumen, folder awal, environment, warna) bisa dibuat di **Pengaturan → Profil terminal lokal**.
- **Tab baru cepat** (Ctrl+Shift+T / ⌘T): popup untuk mencari host atau terminal lokal lalu langsung membukanya.
- **Tab lebih mudah diatur**: klik kanan tab untuk ganti nama, duplikat, atau tutup tab lain / di kanan; urutan tab bisa digeser dengan drag. Pindah tab dengan Ctrl+Tab / Ctrl+Shift+Tab, atau langsung ke tab ke-n dengan Ctrl+1…9 (⌘1…9).
- **Highlight teks** (**Pengaturan → Highlight teks**): beri warna pada keyword atau regex di terminal, misalnya ERROR, WARN, INFO. Profil bisa dipasang ke host, grup, atau terminal lokal tertentu. Import/export JSON format Tabby. Default mati.
- **Shortcut bisa diganti** (**Pengaturan → Shortcut**): tekan kombinasi baru untuk setiap aksi, kosongkan, atau reset ke bawaan. Ada peringatan kalau kombinasi bentrok dengan aksi lain atau biasa dipakai shell.
- **Upload antar-server SFTP**: klik kanan file/folder → **Upload ke ▸** panel SFTP lain yang terbuka, atau drag & drop antar-panel. File dikirim langsung lewat TermUL tanpa file sementara di komputer ini, dan selalu ada konfirmasi folder serta host tujuan (dengan peringatan untuk host PROD).
- **macOS**: tersedia `.app`/`.dmg`, shortcut memakai ⌘, dan **Vault → Ingat di Mac ini** untuk membuka vault lewat Keychain tanpa mengetik master password.
- Shortcut baru: Ctrl+Shift+B / ⇧⌘B tampilkan/sembunyikan daftar host, Ctrl+Shift+D / ⇧⌘D duplikat tab.

## Catatan

- Shortcut yang Anda ganti sendiri selalu diambil TermUL sebelum terminal, jadi tombol itu tidak lagi sampai ke shell. Shortcut bawaan tetap seperti sebelumnya.
- "Ingat di Mac ini" hanya ada di `.app` hasil instalasi, tidak di JAR portable. Setelah instal ulang dari DMG baru, macOS bisa menanyakan izin Keychain sekali lagi: pilih **Always Allow**.
